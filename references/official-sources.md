# 竞彩足球官方来源索引

分析时直接打开对应当期页面。链接于 2026-09-21 核对可达，站点改版后以官网当期导航为准；页面不可访问就标注未核实，不沿用旧赛程或旧奖金。

- [足球竞猜赛程](https://www.sporttery.cn/jc/zqszsc/index.html)：核对编号、开赛时间、玩法开售状态及单关标识（赛程页不显示让球数）。
- [胜平负/让球胜平负固定奖金](https://www.sporttery.cn/jc/jsq/zqspf/index.html)：官方让球数、选项奖金、单关标识；让球为官方公布的整数，符号以主队为基准。
- [比分](https://www.sporttery.cn/jc/jsq/zqbf/)、[半全场](https://www.sporttery.cn/jc/jsq/zqbqc/)、[总进球数](https://www.sporttery.cn/jc/jsq/zqzjq/)、[混合过关](https://www.sporttery.cn/jc/jsq/zqhhgg/)：核对选项与可用串法。
- [竞彩销售时间](https://www.sporttery.cn/help/143831.html?gid=73)：可能调整，以当期公告和实际开售状态为准。
- 规则：[让球胜平负](https://www.sporttery.cn/help/60334.html?gid=2)、[总进球数](https://www.sporttery.cn/help/3195.html?gid=2)（选项 0–6、7+）、[比分](https://www.sporttery.cn/help/3197.html?gid=2)、[半全场](https://www.sporttery.cn/help/3194.html)、[混合过关](https://www.sporttery.cn/help/40213.html)与[自由过关](https://www.sporttery.cn/help/249715.html?gid=2)（不同场次可混玩法，同场不同玩法不得混串，关数上限受玩法约束）、[特殊情况](https://www.sporttery.cn/help/2948.html)（提前、延期、取消或中断按官方规则处理）。

引用当期事实时附页面与北京时间查询时间；官网与旧说明冲突时，以当期公告和销售系统为准。
