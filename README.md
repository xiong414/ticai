# ticai

中国体育彩票竞彩足球赛前分析 Agent Skill。它要求先核对当期官方赛程、玩法、固定奖金和单关资格，再结合赔率、阵容、伤停、天气等信息分析指定场次或当日赛程。

技能定位是**只联网、只读取**：全部输入来自联网检索与网页抓取，不使用、也不要求本地命令行（见下文“限制”）。

## 使用模式

默认走正常模式：四块结构、约 500 字，给出完整依据与风险。两种模式需要**显式**说法才触发，不会自行降级。

**快速模式**——只要一句话总结、单关与串关建议、一张最简图表，约 250 字：

- `快速分析 周三003`、`快速 周三003`

输出固定三块：**总结**（一句话结论）→ **建议**（单关一行、串关一行）→ **图表**（最小表格 + ASCII 概率条，如 `胜 2.05 55% █████░░░░░`）。

数据核验要求不变（不能跳过当期官方数据）；该场该玩法未核实时会写“未核实”，单关与串关建议一并降为观望。过关和混合过关默认仍走正常模式；用户坚持快速版时，只给按已核实场次拼出的最简串关并标明未核实项。

**深挖模式**——主分析之后想进一步了解某支球队或某个联赛：

- `深挖 主队`、`深挖 两队`、`深挖 主队 + 英超`
- `深挖 003 全部`（主队 + 客队 + 所属联赛，最慢）
- `快版深挖 主队`（只给战绩走势、主客场分化、伤停）

深挖只抓点名的目标，目标越多越慢；不提深挖时响应速度与普通分析一致。

## 安装

复制整个 `ticai` 文件夹，保留 `SKILL.md` 和 `references/`：

- DSH：`~/.dsh/skills/ticai/`
- Codex：`~/.codex/skills/ticai/`（或 `~/.agents/skills/ticai/`）
- Claude Code：`~/.claude/skills/ticai/`
- Gemini CLI：`~/.gemini/skills/ticai/`（或 `~/.agents/skills/ticai/`）
- Cursor：`~/.cursor/skills/ticai/`（也支持 `~/.agents/skills/ticai/`）

`agents/openai.yaml` 是 Codex 的界面配置；其他产品可忽略。目标 Agent 需要具备联网查询能力，才能核验实时赛程、奖金与赛前信息。预测只供分析参考，不保证收益。

技能只认一级目录 `<root>/<ticai>/SKILL.md`，更深的嵌套不会被发现。`SKILL.md` 的 frontmatter 要求 `name` 为 kebab-case、`description` 必填，不合规会被宿主静默跳过。

## 更新

改完 `SKILL.md` 或 `references/` 后推送，再同步到宿主技能目录：

```powershell
git pull
powershell -ExecutionPolicy Bypass -File scripts\sync.ps1 -Check   # 只校验，看哪里不一致
powershell -ExecutionPolicy Bypass -File scripts\sync.ps1          # 同步已存在的技能根
```

`scripts/sync.ps1` 会同步到各宿主技能根，并在复制后回读校验文件内容，避免“改了但没生效”。常用参数：

| 参数 | 作用 |
| --- | --- |
| `-Check` | 只校验不修改，逐根报告一致 / 不一致 / 缺失 |
| `-All` | 连同当前不存在的技能根一起创建 |
| `-NoOverwrite` | 只报告实体目录的差异、不动它（默认会直接更新，以修掉陈旧副本） |
| `-Roots` / `-LinkRoots` | 自定义技能根、以及哪些根用目录链接代替复制 |

脚本退出码：`0` 成功、`1` 有技能根未对齐、`2` 源 `SKILL.md` 的 frontmatter 不合规。可以把它放进提交前检查或计划任务里。

默认布局：`~/.dsh/skills` 和 `~/.codex/skills` 存真实副本；`~/.agents/skills` 和 `~/.claude/skills` 用目录链接（优先 symlink，权限不足时自动退化为 junction）指向工作副本，这样它们不需要二次同步。想让所有根都用链接，设 `TICAI_SYNC_LINKS=all`；只想链接部分根，把它设为分号分隔的路径列表。

用链接意味着这些目录指向本地工作副本所在磁盘：副本被移动、重命名或所在磁盘脱机时会失效。想要各宿主完全自包含，改用 `-Roots ... -LinkRoots <不存在的占位路径>` 让所有根都走复制。

脚本的提示信息全部是 ASCII：Windows PowerShell 5.1 会把不带 BOM 的文件按 ANSI 解码，含中文会乱码并可能直接解析失败。

## 限制

- 仅覆盖中国体育彩票竞彩足球；大乐透、排列 3、双色球等其他彩票玩法不适用。
- 只做赛前分析，不代用户下注，不承诺收益。
- **不碰本地命令行**：技能声明为“只联网、只读取”，明确禁止 `pwsh`/`bash`/终端类工具、自建子进程、安装依赖和运行 `scripts/`（该目录只服务于维护者安装）。这条约束写在 `SKILL.md` 的“能力边界（硬约束）”里，属于指令级约束；宿主若要强制禁用命令行，需在宿主侧自行配置（例如 DSH 用不含 shell 工具行的 agent preset），技能文件无法强制。
- 技能本身不含数据，必须由宿主 Agent 联网核验当期赛程、奖金与单关资格。无法核实的项目会标注“未核实”，不会用历史同编号比赛或旧奖金顶替。
- 官方页面多为 JS 渲染，抓取工具需支持渲染才能取到奖金与赛程内容；抓取失败时只允许换用联网检索/网页工具，不允许改用本地命令行。
- 输出走简版格式（见 `SKILL.md` 的“回答格式”），默认约 500 字，以缩短等待时间；需要长报告时直接说明。
- `SKILL.md` 的 frontmatter `description` 用于技能匹配，修改触发场景时保持与技能目录中的摘要一致。
